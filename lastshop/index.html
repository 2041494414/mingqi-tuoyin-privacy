欢迎使用《末日小卖部》。本政策说明游戏在不同发布渠道的版本中如何处理信息，以及您享有的权利。《末日小卖部》是一款单机生存经营游戏，游戏进度、设置和玩法状态默认保存在您的设备本地。

不同渠道版本的差异：

  • TapTap 版：可选接入 TapTap SDK，提供 TapTap 登录与云存档。只有您在游戏设置中打开“TapTap 云存档”并选择“同意并启用”后，才会初始化该 SDK。
  • 好游快爆版：接入好游快爆开发者 SDK，用于快爆账号登录、实名认证、防沉迷和版本更新提醒。您同意本政策后才会初始化该 SDK。
  • 其他渠道版本：不接入任何第三方 SDK，不申请联网权限。

各版本游戏内“设置 → 隐私政策”展示的是该版本适用的政策内容。

一、我们如何收集和使用信息

1. 本地游戏数据（所有版本）

为实现继续游戏、自动存档、店铺经营、库存、装备、探索、种植养殖、烹饪酿造、图鉴和教程等功能，游戏在设备本地（应用内部存储）保存相关数据；声音、帧率、触感反馈和操作偏好也保存在本地。游戏本身未接入线上日志、崩溃统计、数据分析、广告或支付功能。

2. TapTap 登录（仅 TapTap 版，需您启用）

启用云存档后，您可以使用 TapTap 账号登录。登录通过 TapTap SDK 提供的界面（或已安装的 TapTap 客户端）完成。SDK 会处理您的 TapTap 账号标识（如 openId）、昵称、头像和登录授权凭证，用于确认云存档属于您的账号。游戏只在设置页面显示您的 TapTap 昵称，不自行保存您的账号标识、授权凭证或头像。

3. TapTap 云存档（仅 TapTap 版，需您启用）

仅在您点击“上传到云端”，或开启“每晚自动上传”（登录后默认开启，可随时关闭）后，游戏会把本机当前店铺的存档文件上传到 TapTap 云存档服务，与您的 TapTap 账号关联保存。上传内容包括：

  • 存档文件本身（店铺进度、物品、现金、天数等游戏数据）；
  • 一段说明（天数、现金、职业、上传时间和用于校验完整性的摘要）。

只有您在设置中点击“从云端恢复”并确认后，游戏才会下载云端存档，并在本机完成完整校验后写入。恢复前会显示云端与本机的天数和现金对比；本机原有存档会保留为备份，不会被删除。游戏不会自动下载或覆盖本机存档。

云存档相关的本地设置（是否已同意、是否每晚自动上传、上次上传时间、累计游戏时长）保存在设备本地的独立文件中。

4. 快爆账号登录与实名认证（仅好游快爆版）

登录及实名认证通过快爆 SDK 提供的界面完成。SDK 为提供认证、防沉迷、版本更新提醒和安全校验，可能处理以下信息，具体以实际功能及 SDK 政策为准：

  • 账号与实名信息：用户标识、昵称、头像、姓名、身份证号、手机号；
  • 设备与网络信息：AndroidID、OAID、IP 地址、网络类型、运营商、WIFI 参数、系统语言和版本、设备型号与屏幕密度、传感器列表；
  • 应用信息：本应用包名、版本名称、版本号、签名 SHA1 及本应用进程信息。

本游戏不自行保存您的姓名、身份证号、手机号或登录授权码，也不将游戏存档上传至快爆。

5. 设备信息（TapTap 版）

TapTap SDK 为提供登录、云存档、安全校验和故障排查，可能处理设备型号、系统版本、网络类型、IP 地址、应用包名与版本、设备标识符（如 OAID）等信息，具体以 TapTap SDK 隐私政策为准。

6. 您主动提供的反馈

仅在您通过邮件、聊天工具或应用商店主动反馈问题时，我们使用您提供的截图、设备型号、问题描述及联系方式，处理故障或回复咨询，不用于广告推送。

二、第三方 SDK 与共享

1. TapTap SDK（TapSDK Android 4.11.1：基础、登录、云存档模块）
适用版本：TapTap 版（启用云存档后初始化）
提供方：易玩（上海）网络科技有限公司
用途：TapTap 账号登录、云存档上传与下载、必要的安全校验
隐私政策：https://developer.taptap.cn/docs/sdk/start/agreement/

2. 好游快爆开发者 SDK（1.4.4.4）
适用版本：好游快爆版（同意本政策后初始化）
提供方：厦门纯游互动科技有限公司
用途：账号登录、实名认证、游戏时间防沉迷、版本更新检查、唤起快爆游戏详情页及必要的安全校验
隐私政策：https://m.3839.com/html/hykb-265.html

相关信息由 SDK 自行采集并传输至服务提供者处理。好游快爆版接入基础、登录、防沉迷、快爆判断和辅助更新模块，不接入支付、好友或广告模块，不启用读取全部应用安装列表或剪贴板的可选功能。

我们不出售个人信息。除上述用途、您另行授权、依法履行义务或法律规定的情形外，不向其他主体提供您的个人信息。若发生涉及个人信息转移的合并、收购等情况，我们会依法告知接收方，并要求其继续保护信息。

三、设备权限

  • TapTap 版：申请互联网访问和网络状态权限，仅用于 TapTap 登录和云存档；未启用云存档时，游戏不发起这些联网请求。TapTap SDK 会查询设备上是否安装了 TapTap 客户端，以便通过客户端完成登录。
  • 好游快爆版：SDK 需要互联网访问及网络状态权限，以完成登录、实名认证、防沉迷和版本更新检查；其基础模块还声明 GET_TASKS 权限，以辅助检查应用状态。
  • 其他渠道版本：不申请任何需要您授权的设备权限，也不联网。

所有版本均不申请定位、相机、麦克风、通讯录、短信、电话、相册或外部存储权限，并在打包时移除读取全部应用列表等不需要的权限。游戏本地存档使用应用内部存储。

四、信息保存与安全

游戏进度、设置及本政策的同意版本保存在设备本地。TapTap 版的云端存档由 TapTap 云存档服务保存，云端只保留您最近一次上传的一份存档。SDK 相关数据的保存期限、地点和安全措施，以对应 SDK 隐私政策为准。上传和恢复时，游戏会校验存档文件的完整性，校验失败时不写入本机。

我们在处理反馈所需的合理期限内保存您主动提供的信息，之后删除或匿名化处理。请妥善保管设备和账号。卸载游戏或清除应用数据会导致本地进度丢失，请不要用此方式解决登录问题。

五、Cookies 和同类技术

游戏本身不使用网页追踪像素或广告 Cookies；SDK 登录和认证网页的相关技术，以对应 SDK 隐私政策为准。本政策网页由 GitHub Pages 托管，访问处理见 GitHub 隐私声明（https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement），与游戏存档相互独立。

六、您的权利

您可以在游戏设置中随时再次阅读本政策。

TapTap 版中，您可以随时关闭“每晚自动上传”或退出 TapTap 登录，退出登录不会删除本机存档。

以下请求可以通过下方邮箱联系我们：

  • 删除已上传的云端存档；
  • 撤回同意；
  • 访问、更正、删除您主动提供的信息。

TapTap、快爆账号及实名信息相关请求，也可通过对应平台的账号管理渠道或其隐私政策中的联系方式办理。撤回对认证必需信息的授权后，相应服务将无法继续使用。

我们会在十五个工作日内响应合理请求；依法无法满足时会说明原因。

七、未成年人保护

未成年人应在监护人的同意和指导下使用本游戏。不满十四周岁的用户使用账号登录、实名认证或云存档前，应取得监护人同意。好游快爆版按快爆 SDK 的认证和防沉迷结果控制访问。如监护人发现未成年人向我们提供了个人信息，可通过下方方式联系我们处理。

八、政策更新

因功能、法律法规或上架平台要求变化而更新本政策时，我们会通过应用内提示、商店页面或本网页等合理方式告知您；涉及 SDK 接入、云存档等重大变化时，会重新征求您的同意。未经您明确同意，我们不会削减您依法享有的权利。
